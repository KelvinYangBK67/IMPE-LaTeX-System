Inline manuscript glyph specimens for the canonical Showcase.

This directory contains six small images extracted from the user's older
document on Chu bamboo manuscripts; they are contrast-optimized for inline
typesetting. Source references appear in the Showcase footnotes:

1. 武漢大學簡帛研究中心、荊門市博物館編著：《楚地出土戰國簡冊合集（一）：郭店楚墓竹書》，文物出版社，2011，167–168。
2. 馬承源主編：《上海博物館藏戰國楚竹書（四）》，上海古籍出版社，2004，262。
